아래는 Electron + React + Firebase로 만든 데스크톱 앱의 [파일명/기능] 코드야.
이 코드를 리뷰하고 최적화해줘. 아래 항목들을 각각 확인해서, 
문제가 있으면 "어디가 왜 문제인지" 먼저 설명하고 나서 수정된 전체 코드를 줘.

1. 중복 호출 / 중복 상태 업데이트: 같은 동작을 두 군데서 트리거하고 있는 부분이 있는지
   (예: 부모 컴포넌트의 핸들러와 자식 컴포넌트의 래퍼 함수가 같은 IPC/API를 각각 호출하는 경우)
2. 불필요한 리렌더링: useEffect 의존성 배열이 잘못됐거나, 
   매 렌더마다 새로 생성되는 함수/객체를 자식에게 props로 넘기고 있는지
3. Firebase 리스너(onSnapshot) 관련: 언마운트 시 정리(cleanup)가 빠진 곳,
   같은 데이터를 여러 컴포넌트가 각자 구독하고 있는지
4. 메모리 누수 가능성: setInterval/setTimeout, 이벤트 리스너 등이
   해제 없이 계속 쌓이는지
5. 안 쓰는 코드: 죽은 코드(dead code), 이제는 호출되지 않는 함수, 
   미사용 import/변수

각 항목은 "문제 없음"이면 그냥 넘어가고, 문제가 있는 것만 수정해줘.
전체 코드를 작성해줘.
