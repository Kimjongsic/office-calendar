# Context
현재 작성된 교무실 공유 캘린더 코드(React + Tailwind)를 바탕으로, 아래 요구사항에 맞게 코드를 수정해 주려고 합니다. 기존에 구현된 '실시간 Firestore 연동'기능은 완벽히 유지되어야 합니다.

# Modification Requests (수정 요청 사항)
1. **디자인 및 기능 보완**:
   - 밑에 소스코드의 핵심 스팩을 참고해서 현재 캘린더에 코드에 맞게 수정해서 적용시켜줘.
   <소스코드>
	1) 라이브러리 로드 (HTML <head> 내부):
	<script src="https://cdn.jsdelivr.net/npm/sortablejs@1.15.2/Sortable.min.js"></script>

	2) 드래그 핸들 및 상태 디자인 (CSS):
	- 각 일정 카드(.event-card) 내부에 드래그 핸들 아이콘/버튼(`span.drag-handle`)이 존재함.
	- 드래그 중인 임시 카드(.sortable-ghost) 및 선택된 카드(.sortable-chosen)에 대한 스타일 적용.
	- 스타일 정의:
	.drag-handle { cursor: grab; float: right; opacity: .55; padding: 0 4px; font-weight: 700; }
	.drag-handle:active { cursor: grabbing; }
	.sortable-ghost { opacity: .35; }
	.sortable-chosen { transform: scale(1.02); box-shadow: 0 6px 18px rgba(0,0,0,.2); }

	3) 자바스크립트 구현 핵심 로직:
	- 일정 렌더링 시, 각 일정 데이터 구조에 날짜별 순서를 기록할 수 있는 `dayOrder` 객체(`{ [dateString]: index }`)를 포함함.
	- 일정을 그릴 때, 해당 일의 일정들을 `dayOrder[date]` 순서로 정렬(.sort)하여 출력함.
	- 각 날짜 박스(.day)에 Sortable.create()를 바인딩하여 드래그 앤 드롭을 활성화함.
	- 드래그 완료(onEnd 이벤트) 시:
  		가. 드래그가 끝난 날짜 박스(.day) 내부에 들어있는 모든 일정 카드의 ID 순서를 파악함.
  		나. 해당 카드 데이터들의 `dayOrder[date]` 값을 새로운 인덱스(index)로 갱신함.
  		다. 갱신된 데이터를 LocalStorage 및 DB 서버에 저장(Save)하고 새로고침함.

# Output
수정 및 추가된 코드가 적용된 전체 React 컴포넌트 코드를 다시 작성해 주세요. 변경된 부분에는 주석을 달아 설명해 주세요.
